
# Emergency Decision Support System

A web-based project designed to help users make better decisions during emergency situations by presenting relevant information in a simple and interactive way.

The main focus of this project is to make emergency-related information easier to understand and support faster decision-making through a user-friendly interface.

## About the Project

During an emergency, having the right information at the right time can make a difference. This project explores how a web application can be used to organize and present information that may help with emergency decision-making.

I built this project using HTML, CSS, and JavaScript, focusing on the interface, data presentation, and overall user experience.

## Features

- Interactive web interface
- User-friendly design
- Emergency decision support
- Data visualization
- Information presented in an easy-to-understand format
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Piyush-Sharma-009/Emergency-Decision-Support-System.git
   ```

2. Open the project folder.

3. Open the `index.html` file in your browser.

   Alternatively, you can use the Live Server extension in VS Code.
